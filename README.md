# Keshav Soni Portfolio

Portfolio built with plain HTML, CSS, and JavaScript.

Visitors land on the visual portfolio by default, with an optional terminal portfolio available from the header.

Direct routes:
- `index.html` or `#gui` for the visual portfolio
- `#terminal` for the interactive command-line experience
- `#choice` for the mode picker

## Visitor Commands

- `help`
- `about`
- `skills`
- `projects`
- `project 1`
- `education`
- `experience`
- `publications`
- `certifications`
- `contact`
- `resume`
- `neofetch`
- `ls`
- `cd projects`
- `cat about.txt`
- `open resume`
- `open travart`
- `open paper1`
- `theme amber`
- `clear`

The terminal supports command history with Up/Down, Tab autocomplete, virtual folders, aliases, themes, and quick command buttons.

## Customize

Edit the `portfolio` object at the top of `script.js`:

- Name and role
- Email, GitHub, LinkedIn, resume path
- Phone and location
- About text
- Skills
- Projects
- Education
- Experience
- Publications
- Certifications

## Run

Open `index.html` in a browser.
